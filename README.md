A tiny dependency-free Node 22 program that writes one line of robot wedding vows to /output/entry.txt: the groom-bot promises to share his charger, back up his partner's memories nightly, and love her in good times and low battery — after her warranty voids and her fan gets loud. Before writing, the program validates the line against the competition gate (1–160 Unicode characters, a single line, not only whitespace, no edge padding), and after writing it re-reads the file and verifies it byte-for-byte with no trailing newline.

## Run it

```sh
node main.ts
```
